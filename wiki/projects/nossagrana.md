# nossagrana

## Resumo
**PWA de gestão de finanças familiares**, instalável e offline-first.
Self-hosted no homelab, construído 100% via AI coding (Claude Code + Codex).

## Período / Detalhes
- **Tipo:** PWA (Progressive Web App).
- **Construído com:** Claude Code + Codex.
- **Repositório:** https://github.com/leoferolive/nossagrana
- **Demo:** https://nossagrana.leoferolive.com.br

## Tecnologias
- Node + TypeScript (backend).
- React + Vite (frontend).
- PostgreSQL.
