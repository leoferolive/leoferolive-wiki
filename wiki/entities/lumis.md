# Lumis

## Resumo
Passagem entre Out 2018 e Mai 2019 atuando no cliente **SulAmérica
Seguros** — não em produto de seguros, e sim em **canais internos** da
empresa. Foi onde o Leonardo teve o primeiro contato real com
**micro-frontend (Vue.js)**, **OAuth2 / impersonação de sessão**,
**OpenShift** e **Spring Boot** com toolkit completo (JPA, Security,
Eureka). Saiu ainda durante a homologação do projeto principal por uma
proposta irrecusável da Ebix LATAM, que veio acompanhada de promoção a
Sênior.

## Período / Detalhes
- **Período:** Out 2018 → Mai 2019.
- **Cargo:** Analista de Sistemas Pleno.
- **Cliente:** SulAmérica Seguros.
- **Entrada:** alocação inicial temporária para microsserviços de
  integração com **Sensedia** (migração de serviços antigos para Spring
  Boot). Por desempenho, foi efetivado no time misto SulAmérica +
  consultorias.

## Tecnologias
- Java 8.
- Spring Boot, Spring JPA, Spring Security, Eureka.
- Vue.js (primeiro framework frontend moderno do Leonardo — antes só
  HTML/JSP + JavaScript + jQuery).
- DB2 (reaproveitado), Oracle (no projeto de Partes Relacionadas).
- OpenShift (Red Hat / Kubernetes).
- Jenkins, Sonar.

## Achievements / Highlights
- **Sistema de Partes Relacionadas (compliance):** declarações de
  conflito de interesse para diretores e superintendentes. Implementou
  **impersonação de sessão** — admin do compliance preenchia o
  questionário em nome do usuário-alvo. Primeiro contato técnico do
  Leonardo com esse mecanismo de autenticação.
- **Novo Portal RH (projeto principal):** reconstrução do zero em
  **microsserviços + micro-frontend**, mantendo apenas o DB2 existente
  como banco compartilhado. Entregou o módulo **Informe de Rendimentos**
  E2E (backend ao frontend).
- Aprendizado acelerado de Vue.js on-the-job.
- Saiu durante a homologação do Novo Portal RH; **promoção a Sênior** já
  na entrada da Ebix LATAM.
